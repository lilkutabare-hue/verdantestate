## 2. Проверка на баги — первым делом, до любой красоты

2. **`break-ui`** на конструктор, форму, прайс, тарифы: длинные строки, пустые значения, 60 соток + все чипсы, телефон без +7.
3. **Хиро по шагам** (`VE.hero.hold(p)` на стенде; в панели приложения `document.hidden===true` — переопределять): p = 0, .1 … 1 на 390×844 и 1280×800; стыки клипов (разница соседних кадров без всплесков, см. `scratchpad/shot/intro.mjs`), появление текста на .8, луп на .89, указатель на .9. Проверить `prefers-reduced-motion` и `Save-Data`.
4. **Шапка:** прозрачная над хиро, белая после; не прячется над хиро; кнопка `.ve-btn--light` не темнеет на hover (был баг); знак появляется только после стыковки логотипа.
5. **Консоль пустая** на всех ширинах; 404 по медиа нет (после публикации артефакта проверить сетевые запросы к `site/media/scene/*.avif` и `loop.mp4`).
6. **Вес и скорость:** первый экран ≤ 1.5 с на 4G-эмуляции (постер + HEAD), серия пролёта догружается за заставкой; если линия загрузки у владельца идёт дольше 6–8 с — снизить `--q` в `tools/frames.mjs` или сделать серию 1280 px для экранов ≤ 1440.

## 3. Скролл — чтобы было приятно

- Длина хиро 560svh: при 73 кадрах проверить скорость листания на колесе и трекпаде; если «тянется» — 480svh, если «проскакивает» — оставить. Решать снимками трёх точек, не на глаз.
- Инерция `curP += (p − curP) × .16` в `scene.js`: на трекпаде может отставать. Измерить задержку между `progress()` и `curP` при быстром скролле; допустимо ≤ 120 мс.
- После хиро секции должны идти ровным ритмом: один заголовок = один экран смысла. Проверить отступы `--ve-gap` 72/120 на телефоне: тарифы (тёмный блок) не должны «прилипать» к секции сезона.
- Лента «Как проходит сезон» на компьютере закреплена и едет вбок (`.ve-ssn.is-pin`) — проверить, что полоска прогресса доходит до конца и секция отпускает скролл без рывка.
- Параллакс `.ve-px` ±6 %: на слабом телефоне проверить, нет ли дёрганья; при `prefers-reduced-motion` выключен.

## 5. Видео второй волны (моушн — главная фича)

Приоритет по эффекту на сайт / кредиты:

1. **Вертикальный пролёт для телефона** — сейчас 9:16 вырезается из 16:9, и на телефоне теряется половина кадра. Сделать S1v–S4v (эдиты S1–S4 «extend to 9:16») и клипы К1v–К3v в 9:16. Промпты — `docs/prompts-magnific.md` §6. Это самый заметный прирост качества: телефон — главный экран заказчика.
2. **Лупы тарифов T1–T3** (Kling, start = end = стилл, 5 с, «ONLY the light changes: cloud shadow glides»): карточки дышат, вместо параллакса. ≈ 300 КБ каждый.
3. **Луп «после» для шторки B2** (ветер в злаках) — шторка между живым «после» и статичным «до» усиливает контраст.
4. **Луп лета Z1** для сезонов — летняя вкладка живая, остальные стиллы.
5. Пересъёмка К1 с «slower start» не нужна: оба прогона ровные, выбран лучший по стыку.

Сборка: лупы кладутся как `<video muted loop playsinline>` под CSS-маской той же рамки, играют только в поле зрения (IntersectionObserver), ≤ 400 КБ каждый, 1080 по длинной стороне, crf 24.
