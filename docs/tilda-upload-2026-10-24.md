# Заливка в Тильду — что и куда грузить владельцу (24.10.2026)

Цель: сайт целиком живёт в Тильде и открывается в России без VPN. Для этого медиа переезжают с Cloudflare в хранилище файлов Тильды, а скрипт сцены и манифесты уже вшиты в блоки. Порядок ниже — ровно по шагам, каждый шаг проверяется.

## Шаг 0. Проверка хранилища (6 файлов, 5 минут)

1. Тильда → **Настройки сайта → Ещё → Загрузка файлов** (раздел Files; на старых планах его может не быть — тогда сразу сказать мне).
2. Загрузить 6 файлов из `dist/tilda-media-test/` (по одному каждого типа: .jpg, .webp, .mp4, .woff2, .json, .js).
3. Написать, какие приняла, какие нет. Ожидаем: .jpg, .webp, .mp4, .woff2 — да; .json и .js сайту больше не нужны (вшиты в блоки), их результат только для сведения.

Если .webp не прошёл — скажу, пересоберу кадры компьютера в .jpg (телефонные уже .jpg). Если .mp4 не прошёл — пролёт на телефоне будет кадрами (сайт это умеет сам).

## Шаг 1. Медиа в хранилище

1. У меня: `node tools/tilda-media.mjs --pack` → папка `dist/tilda-media/` (≈ 300 файлов, ≈ 60 МБ) и список `dist/tilda-media/СПИСОК.txt`. Имена плоские и уникальные (`scene-tall-00.jpg`, `stills-tariff-basic-l.webp`), Тильда их сохранит.
2. Ты: **Настройки сайта → Ещё → Загрузка файлов** → загрузить все файлы из `dist/tilda-media/` (кроме `СПИСОК.txt` и `pack.json`). Можно пачками по 20–50. Файлы больше 5 МБ в папку не кладутся — их там нет.
3. Ты: когда всё загружено — на той же странице со списком файлов выделить всё (Cmd+A), скопировать (Cmd+C) и вставить в текстовый файл, прислать его мне (или сохранить как `docs/tilda-links.txt`). Нужны ссылки вида `https://static.tildacdn.com/tild…/имя-файла`.
4. У меня: `node tools/tilda-media.mjs --map docs/tilda-links.txt` → карта `docs/media-map.json`; `--check` прогоняет все ссылки (код 200, размер, CORS). Потом `node tools/build.mjs` — блоки в `dist/` собираются уже с адресами Тильды, `dist/ЗАЛИТЬ.html` обновляется.

Если потом появятся новые рендеры — `--pack` отметит в списке только новые файлы, догружаешь только их и присылаешь новые ссылки.

## Шаг 2. HEAD сайта

**Настройки сайта → Ещё → HTML-код для вставки внутрь head** → вставить содержимое `dist/head.html` целиком (копируется кнопкой на листе `dist/ЗАЛИТЬ.html`). Это один раз на сайт, не на страницу. Лимит Тильды 64 КБ — сборка следит, сейчас ≈ 56 КБ.

## Шаг 3. Главная страница

1. Новая страница, адрес `/` (главная). В настройках страницы: без шапки и подвала Тильды, фон белый.
2. Пятнадцать блоков **T123 (HTML-код)** подряд, в порядке листа: 01 шапка … 15 подвал. У каждого блока отступы сверху и снизу 0 (Настройки блока → Отступы). Содержимое каждого — кнопкой «Копировать» с листа `dist/ЗАЛИТЬ.html`, вставить как есть, ничего не править внутри Тильды.
3. Опубликовать страницу. После публикации один раз Cmd+Shift+R — Тильда и браузер кэшируют HEAD.

## Шаг 4. Страницы политики и согласия

Две страницы с адресами **/policy** и **/consent**, на каждой один блок T123 из листа (`t123-policy`, `t123-consent`). Шапку и подвал Тильды тоже выключить. Ссылки на них в подвале и в форме уже ведут на эти адреса. Реквизиты в текстах появятся, когда заказчик пришлёт данные (`docs/client-data.json`); до этого там метки — публиковать как черновик можно, но заявки на домене открывать только с заполненной политикой.

## Шаг 5. Настройки сайта

- **Фавикон:** Настройки сайта → Ещё → Фавикон → загрузить `docs/site/favicon.svg`; для iPhone — `docs/site/apple-touch-icon.png` (там же, «иконка для iOS»).
- **Заголовок и описание** главной: «Verdant Estate — уход за частными садами в Москве и области» / «Постоянное управление садом: один договор, один ответственный, весь сад под контролем». Картинка для соцсетей — `docs/site/media/scene/poster-wide.webp` (или её jpg-версия, если Тильда не возьмёт webp).
- **Домен** verdantestate.ru: зарегистрировать (21.10 в реестре его не было), в Тильде — Настройки сайта → Домен, DNS по инструкции Тильды. До домена — адрес `*.tilda.ws`.
- Шрифты сайта Тильды не трогать: свои шрифты сайт берёт из хранилища (Cormorant), системный гротеск — с устройства.

## Шаг 6. Бот заявок

Заказчик открывает @VerdantEstateServiceBot, нажимает Start и шлёт `/test`. Потом тестовая заявка с опубликованной страницы. Если ник заказчика в Telegram другой, чем сейчас в `tools/form-worker/wrangler.toml` (`ALLOW_USER`), — сказать мне, поправлю и передеплою воркер `verdant-form`.

## Шаг 7. Живая проверка (делаю я после твоего «залил»)

Сверка живой страницы со сборкой (баннеры блоков, что Тильда вырезала), матрица устройств на живом адресе, консоль, вес на 4G, запись с iPhone по плавности. Если Тильда что-то вырезала — правлю исходник и ты перезаливаешь один блок.

## Что уже готово к этому

- `dist/ЗАЛИТЬ.html` — лист с кнопками «Копировать» на HEAD и каждый блок, номер сборки сверху, отметки «залито».
- `dist/tilda-media-test/` — 6 пробных файлов.
- `dist/tilda-media/` — полный пакет медиа (после `--pack`).
- Сцена и лупы не требуют отдельных файлов .js/.json на хостинге — всё внутри HEAD и блока хиро.
- Пролёт: куски видео по клипам ≤ 4,8 МБ (под лимит Тильды), на телефоне 720×1280, на компьютере 1440×810; если видео не идёт (режут линию) — через 3,5 с сцена сама переходит на кадры.
