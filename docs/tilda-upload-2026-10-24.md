# Заливка в Тильду — что и куда грузить владельцу (24.10.2026, исправлено вечером)

Цель: сайт целиком живёт в Тильде и открывается в России без VPN. Блоки и HEAD — в Тильду, медиа — на хост, который в России не режут. **На тарифе Personal в Тильде нет раздела «Загрузка файлов»** (он только на Business), поэтому медиа кладём в объектное хранилище Яндекса: пути сохраняются, карта ссылок не нужна, стоит копейки.

## Шаг 1. Медиа в хранилище (20 минут, один раз)

1. Яндекс Облако (cloud.yandex.ru) → создать платёжный аккаунт (карта нужна; 100 МБ хранения и трафик сайта — десятки рублей в месяц, есть стартовый грант).
2. Object Storage → **Создать бакет**: имя `verdant-media`, класс стандартный, **доступ на чтение объектов — публичный**. Во вкладке **CORS** добавить правило: методы GET и HEAD, источники `*`, заголовки `*`.
3. Сервисные аккаунты → создать `verdant-media` с ролью `storage.editor` → **Создать статический ключ доступа**, скопировать идентификатор и секрет (секрет показывается один раз).
4. На маке создать файл `deploy/.s3env` (папка `deploy/` в git не идёт) с четырьмя строками:
   ```
   S3_ENDPOINT=https://storage.yandexcloud.net
   S3_BUCKET=verdant-media
   AWS_ACCESS_KEY_ID=<идентификатор ключа>
   AWS_SECRET_ACCESS_KEY=<секрет>
   ```
5. Один раз `brew install awscli`, затем:
   ```bash
   zsh tools/media-sync.sh
   ```
   Скрипт заливает `docs/site/media`, `fonts`, `js` с правильными типами и кешем, в конце записывает адрес хранилища в `docs/media-base.txt`.
6. Проверка: `zsh tools/media-sync.sh --check` — четыре файла должны отвечать 200 с `access-control-allow-origin: *`.
7. Пересобрать: `node tools/build.mjs && node tools/tilda-sheet.mjs` — блоки и лист `dist/ЗАЛИТЬ.html` теперь с адресами хранилища.

Если захочешь Business-тариф Тильды — есть второй путь через её «Загрузку файлов» (`node tools/tilda-media.mjs --pack` → заливка → список ссылок → `--map`), он тоже готов; но хранилище Яндекса проще и дешевле.

## Шаг 2. HEAD сайта

**Настройки сайта → Ещё → HTML-код для вставки внутрь head** (в разделе «Ещё» это ниже, после RSS) → вставить содержимое `dist/head.html` целиком, копируется кнопкой с листа `dist/ЗАЛИТЬ.html`. Один раз на сайт. Делать после шага 1.

## Шаг 3. Главная страница

1. Страница с адресом `/` (главная). Настройки страницы: без шапки и подвала Тильды.
2. Пятнадцать блоков **T123 (HTML-код)** подряд по листу: 01 шапка … 15 подвал. Отступы каждого блока сверху и снизу 0. Код не править внутри Тильды.
3. Опубликовать. После публикации один раз Cmd+Shift+R — Тильда и браузер кэшируют HEAD.

## Шаг 4. Страницы /policy и /consent

Две страницы с этими адресами, на каждой один блок T123 с листа (П и С). Шапку и подвал Тильды выключить. Реквизиты появятся, когда заказчик пришлёт данные.

## Шаг 5. Настройки сайта

- **Фавикон:** Настройки сайта → Главное → Favicon → **Загрузить файл** → `docs/site/favicon.ico` (или `docs/site/favicon-32.png`). Тильда принимает только ico/png/jpeg, svg — по ссылке «здесь» в том же разделе, туда же `docs/site/apple-touch-icon.png` для iPhone.
- **Главная страница → SEO:** заголовок «Verdant Estate — уход за частными садами в Москве и области», описание «Постоянное управление садом: один договор, один ответственный, весь сад под контролем», картинка для соцсетей — `docs/site/media/scene/poster-wide.webp` (если не примет webp — пришлю jpg).
- **Домен:** зарегистрировать verdantestate.ru (21.10 в реестре его не было), затем Настройки сайта → Домен, DNS по инструкции Тильды. До домена — адрес на tilda.ws.
- **Шрифты** Тильды не трогать: сайт свои грузит сам.

## Шаг 6. Бот заявок

Заказчик открывает @VerdantEstateServiceBot, нажимает Start, шлёт `/test`. Потом тестовая заявка с опубликованной страницы. Если ник заказчика другой — сказать мне, поправлю `ALLOW_USER` и передеплою `verdant-form`.

## Шаг 7. Живая проверка (делаю я после твоего «залил»)

Сверка живой страницы со сборкой, матрица устройств на живом адресе, консоль, вес на 4G, запись с iPhone.

## Что уже готово к этому

- `dist/ЗАЛИТЬ.html` — лист с кнопками «Копировать» на HEAD и каждый блок, номер сборки, отметки «залито».
- `tools/media-sync.sh` — заливка в хранилище одной командой; `docs/media-base.txt` переключает сборку на него.
- Сцена и лупы не требуют отдельных файлов на хостинге, кроме кадров и видео: скрипт и манифесты внутри HEAD и блока хиро.
- Пролёт — куски видео по клипам ≤ 4,8 МБ; если видео не идёт, через 3,5 с сцена переходит на кадры.
